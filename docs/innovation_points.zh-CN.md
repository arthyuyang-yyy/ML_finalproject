# 核心创新点

## 1. 重叠感知路由

系统估计每个音频片段的重叠程度，并选择不同处理路径，而不是对所有片段使用成本最高的方法。

**低重叠路径**

- VAD 分段
- 说话人嵌入提取
- 说话人聚类
- ASR 转写

**高重叠路径**

- 语音分离或候选生成
- 多个可能的转写和说话人候选
- 保留不确定性
- 使用 LLM 辅助推理，但不强制输出唯一答案

该路由设计在计算成本与识别质量之间取得平衡，并使路由决策本身可被评估。

## 2. 不确定性感知的高重叠处理

一个高重叠片段可能存在多个合理解释。系统可以保留候选转写 A、候选转写 B、可能的说话人归属、重叠分数、置信度和不确定性说明。

后续模块不能悄悄将这些候选压缩为一个答案。LLM 应明确标注不确定内容，避免将缺乏支持的猜测表达为事实。

## 3. 元信息感知 LLM 后处理

LLM 接收结构化元信息，包括说话人标签、时间戳、重叠分数、ASR 置信度、说话人置信度、处理路径、候选解释、领域词汇和历史记忆上下文。

LLM 执行转写纠错、说话人归属检查、不确定性保留、观点提取、冲突与共识检测、决策提取、行动项提取和基于证据的摘要生成。每条决策和行动项都应关联带时间戳的证据。

## 4. Episodic Memory / 情景记忆

每个会议 episode 保存：

- 会议 ID 和事件 ID；
- 时间范围、说话人和主题；
- 原始与纠正后转写；
- 重叠与置信度信息；
- 候选解释；
- 决策、行动项和证据文本；
- 实现检索后使用的嵌入向量。

该设计支持会议问答、历史与跨会议回忆、行动项检索、说话人检索，以及带时间戳的可追溯证据。

**实现状态**：episode 现已按会议事件分组（继承事件 ID 与主题），并在事件未覆盖的片段上按时间间隔兜底分段。检索已实现语义检索（安装 `sentence-transformers` 时启用，缺省回退到中英文词法匹配），并支持按会议 ID、说话人、时间范围过滤；每条检索结果附带 `retrieval_score` 与 `retrieval_method`，使排序可追溯。

## 5. 超越 WER 与 DER 的评估

WER 和 DER 仍然有价值，但不能衡量会议助手是否可信。本项目还将评估重叠路由准确率、候选有效性、说话人归属准确率、不确定性保留质量、行动项提取准确率、RAG 问答准确率、证据命中率和幻觉率。
