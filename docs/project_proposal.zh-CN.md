# 项目提案

## 研究问题

与传统的 ASR 到摘要流程相比，重叠感知路由、显式不确定性表示和 Episodic Memory 能否使多人会议理解更加准确、高效且可验证？

## 问题定义

重叠语音会同时造成 ASR 和说话人归属错误。传统流程通常只向 LLM 提供一个确定性转写，LLM 可能将不确定输入变成自信但缺乏支持的摘要。同时，这类流程常常丢弃后续会议问答所需的片段级证据。

## 提出方法

本项目将低重叠与高重叠片段路由到不同处理路径。高重叠片段可以产生多个转写和说话人候选。元信息感知 LLM 保留不确定性，并提取有证据支持的决策和行动项。最终输出被存储为 Episodic Memory，以支持可追溯问答和跨会议回忆。

## 预期贡献

- 模块化的双路径会议音频流程。
- 统一的不确定性感知片段元信息 Schema。
- 面向可验证会议理解的 Episodic Memory 表示。
- 覆盖路由、候选、不确定性、检索、证据和幻觉的评估框架。

## 项目范围

第一阶段定义研究设计与接口，不加载重模型。后续阶段将实现可替换的基线、建立人工标注测试集，并进行可控消融实验。
