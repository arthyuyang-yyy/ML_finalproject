# 实验计划

## 通用设置

建立人工标注的评估集，包含时间戳、说话人标签、重叠标签、转写文本、主题、决策和行动项。报告总体指标，并分别报告低重叠与高重叠区域结果。

## 实验 1：重叠路由

将预测的 `low_overlap_cluster` 和 `high_overlap_candidate` 路由与人工重叠标签比较。报告准确率、精确率、召回率、F1，以及不同阈值下的后续成本与质量权衡。

## 实验 2：高重叠候选生成

比较候选输出与强制单一转写。评估候选 oracle WER、top-1 WER、说话人假设覆盖率、人工评定的候选有效性，以及有用信息是否能够在模糊重叠区域中保留。

## 实验 3：元信息感知 LLM 后处理

比较：

1. 纯转写 + LLM；
2. 转写 + 说话人标签 + LLM；
3. 转写 + 说话人标签 + 重叠/置信度元信息 + LLM。

测量纠错质量、说话人归属准确率、不确定性保留质量、决策提取和行动项提取效果。

## 实验 4：Episodic Memory 问答

比较：

1. 普通摘要问答；
2. 基于纯转写的 RAG；
3. 说话人感知的 Episodic Memory 问答。

测量问答准确率、说话人检索准确率、行动项检索、跨会议回忆和证据命中率。

## 实验 5：幻觉与证据评估

评估回答、决策和行动项是否得到带时间戳证据的支持。报告证据精确率/召回率、无支持声明率、幻觉率，以及置信度和不确定性说明的校准程度。
